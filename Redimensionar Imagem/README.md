# Redimensionador de Imagem

Redimensiona uma ou várias imagens de uma vez. Tudo acontece no navegador: nenhuma imagem é enviada para servidores.

🌐 [Acessar](https://cgb102000.github.io/Projetos-publicos/Redimensionar%20Imagem/)

## Funcionalidades

- Várias imagens de uma vez
- Manter proporção (informe só a largura, só a altura, ou as duas como limite)
- Saída em JPEG, PNG, WebP ou no mesmo formato da original
- Controle de qualidade
- Prévia, tamanho antes/depois e download individual ou de todas
- Mensagem de erro para arquivos que não são imagens

## Versão desktop

O arquivo `index.py` é uma versão para computador feita com Tkinter e Pillow:

```bash
pip install pillow
python index.py
```
